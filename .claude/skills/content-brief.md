# Content Brief Creation Procedure

## Purpose

Step-by-step procedure for creating a comprehensive SEO content brief that gives a writer everything needed to produce content that ranks for target keywords and satisfies search intent.

## Prerequisites

- Target keyword(s) from keyword-researcher
- Access to search results for SERP analysis
- Competitor content for the target keyword
- Site URL and existing content inventory
- Brand voice guidelines (if available)

## Procedure

### Step 1: Target Keyword Analysis

**Actions:**
- Confirm primary keyword and search volume estimate
- Identify 5-15 secondary/related keywords to include naturally
- Classify search intent:
  - **Informational**: Searcher wants to learn (how, what, why, guide)
  - **Navigational**: Searcher wants a specific page or brand
  - **Commercial**: Searcher is researching before buying (best, review, comparison)
  - **Transactional**: Searcher wants to take action (buy, sign up, download)
- Map keywords to intent and content format expectations
- Note any keyword modifiers that indicate specific content needs (year, location, "free")

**Output:** Keyword target table with volume, difficulty, and intent

### Step 2: SERP Analysis

**Actions:**
- Search the primary keyword and analyse the top 10 results
- Record for each result:
  - URL, title tag, meta description
  - Content type (guide, list, tool, video, product page)
  - Estimated word count
  - Key topics covered
  - Unique angles or differentiators
- Identify SERP features present:
  - Featured Snippet (type: paragraph, list, table)
  - People Also Ask questions
  - AI Overview (if present — note sources cited)
  - Video carousel, image pack, local pack
  - Knowledge panel
- Note content format patterns (do top results use videos, tables, infographics?)

**Output:** SERP analysis table, SERP feature inventory

### Step 3: Competitor Content Analysis

**Actions:**
- Select top 3-5 ranking competitors for deep analysis
- For each competitor page, document:
  - Content structure (heading hierarchy)
  - Topics and subtopics covered
  - Content depth and comprehensiveness
  - Unique value (original data, expert quotes, tools)
  - Weaknesses (outdated info, missing topics, poor UX)
  - Internal/external links
  - Media usage (images, videos, infographics)
  - Schema markup present
- Identify the content gap — what are competitors missing?

**Output:** Competitor comparison matrix, content gap notes

### Step 4: Content Outline Creation

**Actions:**
- Write the H1 (include primary keyword, compelling, under 60 chars)
- Structure H2 headings covering all essential subtopics
- Add H3 headings for detailed subsections
- For each section, note:
  - Key points to cover
  - Secondary keywords to include
  - Specific data/examples to reference
  - Suggested content format (paragraph, list, table, comparison)
- Order sections by user journey logic (problem → solution → action)
- Include an FAQ section if People Also Ask is prominent
- Plan visual elements (where images, tables, or diagrams add value)

**Output:** Full content outline with keyword placement notes

### Step 5: Word Count and Content Depth Recommendation

**Actions:**
- Calculate average word count of top 5 ranking pages
- Recommend word count range (not a fixed target — quality over quantity)
- Identify minimum topics that must be covered for comprehensiveness
- Note where depth matters most (core topic) vs where brevity is better (supporting sections)
- Flag if the intent suggests shorter content (transactional pages don't need 3000 words)

**Output:** Word count recommendation with rationale

### Step 6: EEAT Signal Planning

**Actions:**
- Assess EEAT requirements for the topic:
  - **YMYL topics** (health, finance, legal): require strong EEAT signals
  - **General topics**: standard EEAT sufficient
- Plan Experience signals (first-hand experience, case studies, original data)
- Plan Expertise signals (author credentials, technical depth, accurate information)
- Plan Authoritativeness signals (citations, expert quotes, data sources)
- Plan Trustworthiness signals (transparency, sources, editorial standards)

**Output:** EEAT requirements checklist for the content

### Step 7: Internal Linking Plan

**Actions:**
- Identify 3-5 existing pages to link TO from this content
- Identify existing pages that should link TO this new content
- Suggest anchor text for each internal link (natural, descriptive)
- Check for cannibalisation — ensure no existing page targets the same keyword
- Plan contextual placement (links within relevant paragraphs, not forced)

**Output:** Internal linking table (anchor text, target URL, direction)

### Step 8: Schema Recommendation

**Actions:**
- Determine appropriate schema type(s) for the content:
  - Article/BlogPosting for editorial content
  - HowTo for step-by-step guides
  - FAQPage for FAQ sections
  - Product/Review for product content
  - BreadcrumbList for navigation context
- List required and recommended properties for each schema type

**Output:** Schema type recommendation with key properties

### Step 9: Metadata Drafting

**Actions:**
- Write title tag:
  - Include primary keyword (front-loaded when natural)
  - Maximum 60 characters (aim for 50-55 to avoid truncation)
  - Include brand name if space permits
  - Make it compelling — not just keyword + brand
- Write meta description:
  - Maximum 155 characters
  - Include primary keyword naturally
  - Include a call to action or value proposition
  - Make it click-worthy — this is ad copy for organic
- Suggest URL slug (short, keyword-inclusive, hyphenated)

**Output:** Title tag, meta description, URL slug

## Final Output

Compile all steps into a Content Brief document following the seo-writer output format. The brief should be self-contained — a writer with no SEO knowledge should be able to produce optimised content from it alone.
