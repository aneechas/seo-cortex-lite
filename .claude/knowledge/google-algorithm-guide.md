# Google Algorithm Awareness Guide

## Purpose

Key algorithm systems that SEO agents must understand. Knowing what each system targets helps agents align recommendations with how Google evaluates content and links.

## Core Ranking Systems

### Core Updates (Quality/Relevance)
**What it targets:** Overall content quality, relevance, and user satisfaction.
**Frequency:** Several times per year (broad core updates).
**Alignment strategy:**
- Produce the best content for target queries
- Ensure content comprehensively covers topics
- Match content to search intent precisely
- Maintain strong EEAT signals across the site
- Regularly refresh and update existing content

**Recovery from negative impact:** Improve content quality holistically — there is no single fix. Core updates reward the best overall content, not specific technical changes.

### Helpful Content System
**What it targets:** Content created primarily for search engines rather than people.
**Key signals:**
- Content that feels auto-generated or templated without value
- Content that doesn't deliver on its title/heading promises
- Content that exists only because a keyword has volume
- Sites with large volumes of content on unrelated topics
**Alignment strategy:**
- Write for humans first, optimise for search second
- Ensure every page provides genuine value a visitor would appreciate
- Stay within topical expertise — don't create content purely for traffic
- Remove or consolidate low-value pages that dilute site quality
- Demonstrate real experience and expertise in content

### SpamBrain (Spam Detection)
**What it targets:** Link spam, content spam, and other manipulative practices.
**What it catches:**
- Purchased or artificially generated backlinks
- Link spam networks and PBNs
- Hacked sites injecting spam content
- Auto-generated spam content at scale
- Keyword stuffing and cloaking
**Alignment strategy:** Follow Google's spam policies. If a practice feels manipulative, it probably is.

### Page Experience System
**What it targets:** User experience quality, particularly Core Web Vitals.
**Components:**
- Core Web Vitals (LCP, INP, CLS)
- Mobile friendliness
- HTTPS security
- No intrusive interstitials
**Alignment strategy:** Pass all Core Web Vitals thresholds. Page experience is a tiebreaker — it won't rank poor content, but it helps good content edge out competitors.

### Product Reviews System
**What it targets:** Quality of product review content.
**Key signals:**
- First-hand experience with the product
- Quantitative measurements and comparisons
- Unique information beyond manufacturer specs
- Pros AND cons (balanced assessment)
- Evidence of actual use (photos, performance data)
**Alignment strategy:** Only publish reviews based on genuine experience. Include specific, measurable observations.

### Link Spam Update
**What it targets:** Manipulative link building practices.
**What it catches:**
- Large-scale link buying/selling
- Excessive link exchanges
- Automated link building
- Low-quality directory spam
- Guest post networks built purely for links
**Alignment strategy:** Earn links through quality content, genuine relationships, and digital PR. Never buy, sell, or systematically exchange links.

## Algorithm Impact Assessment

When an algorithm update is announced or suspected:
1. Check timing: correlate traffic changes with confirmed update dates
2. Check scope: is the impact site-wide or limited to specific sections/pages?
3. Check pattern: which pages gained/lost? What do they have in common?
4. Check competitors: did they gain or lose similarly?
5. Assess which system is likely responsible based on the pattern
6. Recommend alignment improvements for that specific system

## Key Principle

Google's algorithms collectively reward sites that provide the most helpful, accurate, and trustworthy content for each query. There are no shortcuts — and practices that attempt to game any single system eventually get caught by another.
